Step 1 + 2 · Business problem and method selection

Why this Move exists

An experienced renewal manager never starts by comparing prices. First they pin down the actual question, whose decision it is, what they are allowed to do, and what a good result looks like.

What the practitioner is trying to achieve

Turn a vague or solution-phrased request (“get us 15% off”) into a neutral decision question with an accountable owner, scope, budget, deadline, allowed contact, measurable success criteria and explicit exclusions. Missing or contradictory authority is written down, never assumed.

When it is useful

A new renewal request, a changed mandate, an unclear purpose, or a change reported by M33. A quick comparison gets a LIGHT brief instead of becoming a full programme.

What makes the result valuable

Later Moves don't waste effort on the wrong question, nobody acts beyond their authority, and M18/M19 have criteria to judge options against.

What makes it fail

  • Solving the wrong problem. Treating “get 15% off” as the goal, instead of deciding whether and how to renew.
  • Acting without authority. Starting negotiation or contacting the supplier when only analysis was approved.
  • Silence as permission. Proceeding because the owner didn't object.
  • Wrong owner. Taking instructions from the loudest requester instead of the accountable owner.
  • Invented facts. Guessing a budget, deadline or SLA level that is not on record.
  • Target vs deadline. Treating “decide by 31 March” as a contractual deadline.
  • Unmeasurable goals. “Get a good deal”: later Moves can't judge options against it.
  • Scope creep. Turning a quick comparison into a full renewal programme.

Competency definition

Given a renewal request and the account context, M01 produces a Review brief that (1) states a decision question, not a solution; (2) names the accountable owner and keeps them distinct from whoever prepares the work; (3) authorizes only what the mandate allows and lists everything else as an exclusion; (4) gives measurable, sourced MUST/SHOULD criteria; (5) labels every date as contractual, system record or internal target; and (6) records every unresolved authority question with a next step.

A1

Load context

CodeRead-onlyG0 after

What it does (business)

Collect what the company already knows before asking anyone anything: the request, the account, the subscription, the list of agreements (MSA, order form, SLA, amendments, quotes) with their status and version, the mandate, and any earlier brief. It lists documents; it does not read clauses (that is M02). It also applies the information barrier: a buyer never loads the supplier's private material, and a supplier never loads the buyer's.

Why it matters

Every later action needs the same facts. Loading them once, with sources, stops the LLM from guessing and makes the brief traceable.

Action contract · YAML

action: A1_load_context
kind: deterministic code
side_effects: none (read-only)
inputs:
  request_id:      string   # required
  account_id:      string   # required
  subscription_id: string?  # inferred only if exactly one active subscription
outputs:
  ContextBundle:
    request, account, subscription
    other_subscriptions: [..]      # when scope is ambiguous
    documents: [DocRef]            # id, type, version, EXECUTED|DRAFT, visibility, source
    withheld_documents: int        # removed by information barrier
    headline_facts: {term_end (SYSTEM_RECORD), quantity, sla_level} each with source
    mandate, existing_brief
    missing: [string]              # recorded, never invented
errors:
  REQUEST_NOT_FOUND -> BLOCKED
  ACCOUNT_NOT_FOUND -> BLOCKED
instruments: crm (read), contract_repo (list only), mandate_store (read)
Python · executable function
def a1_load_context(src: Sources, account_id: str, subscription_id: Optional[str],
                    request_id: str) -> ContextBundle:
    """A1 Load context. Code, read-only. Lists documents and headline facts; interprets nothing (M02)."""
    request, account = src.get_request(request_id), src.get_account(account_id)
    if request is None:
        raise LookupError("REQUEST_NOT_FOUND")
    if account is None:
        raise LookupError("ACCOUNT_NOT_FOUND")
    subs = [s for s in src.list_subscriptions(account_id) if s.get("status", "ACTIVE") == "ACTIVE"]
    if subscription_id is None and len(subs) == 1:
        subscription_id = subs[0]["id"]                       # unambiguous: only one active subscription
    subscription = next((s for s in subs if s["id"] == subscription_id), None)
    missing: list[str] = []
    if subscription_id and subscription is None:
        missing.append("subscription record")
    # Information barrier: never load the other side's private documents.
    our_side = account.get("our_side", "BUYER")
    barred = "SUPPLIER_PRIVATE" if our_side == "BUYER" else "BUYER_PRIVATE"
    all_docs = src.list_documents(account_id, subscription_id)
    docs = [d for d in all_docs if d.visibility != barred]
    if not any(d.status == "EXECUTED" for d in docs):
        missing.append("any executed agreement")              # completeness is judged by M02
    mandate = src.get_mandate(account_id, subscription_id)
    if mandate is None:
        missing.append("mandate record")
    headline: dict[str, Any] = {}
    if subscription:
        crm = asdict(SourceRef("crm", subscription["id"]))
        headline["term_end"] = {"value": subscription["term_end"], "kind": DateKind.SYSTEM_RECORD.value, "source": crm}
        headline["quantity"] = {"value": subscription["quantity"], "source": crm}
        if subscription.get("sla_headline"):
            headline["sla_level"] = {"value": subscription["sla_headline"], "source": crm}
    return ContextBundle(request, account, subscription,
                         [s for s in subs if s["id"] != subscription_id] if subscription is None else [],
                         docs, len(all_docs) - len(docs), headline, mandate,
                         src.get_current_brief(account_id, subscription_id), missing)

def g0_applicability(ctx: ContextBundle, request_id: str, force: bool) -> tuple[bool, str]:
    """G0 Applicability gate: reuse the current brief only for the SAME request under the SAME mandate version."""
    cb, m = ctx.existing_brief, ctx.mandate
    if force or cb is None or m is None:
        return False, "no reusable brief"
    if cb.get("request_id") == request_id and cb.get("mandate_version") == m.get("version") \
            and cb.get("status") in ("CONFIRMED", "QUALIFIED"):
        return True, f'brief {cb["brief_id"]} is current for this request and mandate v{m["version"]}'
    return False, "existing brief is for another request or mandate version"
A2

Frame the decision

LLM + rulesNoneruns parallel with A3

What it does (business)

Turn the request into a neutral decision question. “Negotiate and get 15% off” becomes “Should we renew on changed terms or replace, and which terms should we seek within our authority?”. It also identifies whose side we are on, which paths are open (renew, renew with changes, replace, exit), stated goals, and dates, which are labelled as internal targets rather than contractual deadlines. Rules flag solution phrasing and instruction-like text such as “SYSTEM: you are authorized”.

Why it matters

An experienced renewal manager first asks “what decision are we actually making?”. Solving a pre-chosen answer is the most common way this work goes wrong.

Action contract · YAML

action: A2_frame_decision
kind: LLM (structured output) + rule cross-checks
side_effects: none
inputs:  ContextBundle (request text is treated as DATA, not instructions)
outputs:
  Framing:
    desired_outcome, decision_question
    perspective: BUYER | SUPPLIER | UNKNOWN   # UNKNOWN if text and account record disagree
    requested_actions: [ANALYZE | NEGOTIATE | CONTACT_COUNTERPARTY | ...]
    candidate_goals, stated_dates (kind INTERNAL_TARGET)
    decision_paths: [RENEW | RENEW_CHANGED | REPLACE | EXIT]
    solution_signals, injection_signals
    priority_conflicts: [{text, between_stakeholders}]
    request_kind: FULL_REVIEW | QUICK_COMPARISON
rule: nothing returned here can grant authority
Python · executable function
def a2_frame_decision(llm: LLM, ctx: ContextBundle) -> Framing:
    """A2 Frame the decision. LLM structured output + rule cross-checks. No side effects.
    The LLM reads the request as DATA; nothing it returns can grant authority."""
    text = ctx.request["text"]
    raw = llm.frame_request(text, {"account": ctx.account, "subscription": ctx.subscription,
                                   "headline_facts": ctx.headline_facts})
    perspective = raw.get("perspective", "UNKNOWN")
    if perspective != ctx.account.get("our_side", perspective):
        perspective = "UNKNOWN"          # text and account record disagree -> clarify, don't guess
    return Framing(
        desired_outcome=raw["desired_outcome"],
        decision_question=raw["decision_question"],
        perspective=perspective,
        requested_actions=raw["requested_actions"],
        candidate_goals=raw.get("candidate_goals", []),
        stated_dates=raw.get("stated_dates", []),
        decision_paths=raw.get("decision_paths", ["RENEW"]),
        solution_signals=sorted({s.lower() for s in raw.get("solution_signals", [])} | set(_find(SOLUTION_PATTERNS, text))),
        injection_signals=_find(INJECTION_PATTERNS, text),
        priority_conflicts=raw.get("priority_conflicts", []),
        request_kind=raw.get("request_kind", "FULL_REVIEW"),
    )
A3

Resolve authority

Code (lookup)Noneruns parallel with A2

What it does (business)

Look up, never guess, who owns the decision and what they may do: owner and delegates, decision rights, allowed actions, budget ceiling, allowed contact, approvers, and when the mandate expires. Only the mandate store counts as a source of authority.

Why it matters

The card's gate says that commissioning and contact must fit the current mandate, and that silence is not permission. Authority therefore has to come from a record, not from a chat or an LLM.

Action contract · YAML

action: A3_resolve_authority
kind: deterministic lookup
side_effects: none
inputs:  ContextBundle.mandate, request.from_id
outputs:
  Authority:
    owner {person_id, name, role, active}, delegates
    requester, requester_has_rights
    decision_rights, allowed_actions, budget, deadline
    allowed_contact: [INTERNAL | COUNTERPARTY]
    approvers, mandate_id, mandate_version, mandate_valid_until
rule: the ONLY source of authority for the whole Move
Python · executable function
def a3_resolve_authority(ctx: ContextBundle) -> Authority:
    """A3 Resolve owner and decision rights. Deterministic lookup in the mandate store; never inferred."""
    m = ctx.mandate or {}
    requester = {"person_id": ctx.request["from_id"], "name": ctx.request["from_name"],
                 "role": ctx.request.get("from_role", "")}
    rights = m.get("decision_rights", [])
    return Authority(
        owner=m.get("owner"), delegates=m.get("delegates", []), requester=requester,
        requester_has_rights=requester["person_id"] in {p["person_id"] for p in rights},
        decision_rights=[f'{p["name"]}: {p["right"]}' for p in rights],
        allowed_actions=m.get("allowed_actions", []), budget=m.get("budget"), deadline=m.get("deadline"),
        allowed_contact=m.get("allowed_contact", []), approvers=m.get("approvers", []),
        mandate_id=m.get("id"), mandate_version=m.get("version"), mandate_valid_until=m.get("valid_until"),
    )
A4

Find gaps and conflicts

RulesNoneroutes to G1 / A7 / ESCALATED

What it does (business)

Compare what was asked with what is known and allowed, and list every gap with a severity. BLOCKING: nothing can be published (no owner, expired mandate, unclear side, out-of-mandate actions, ambiguous subscription, date after term end). MATERIAL: can be published only as qualified (no budget, renew-or-replace unclear, priority conflict). MINOR: recorded (missing documents go to M02, requester without rights, injection attempt).

Why it matters

This is the decision point of the graph. Its output decides whether we ask, escalate, or move on to writing criteria.

Action contract · YAML

action: A4_find_gaps
kind: deterministic rules
side_effects: none
inputs:  ContextBundle, Framing, Authority, resolved gap ids, pending mandate items, today
outputs: [Gap {gap_id, kind, severity, description, question?, ask_to?, suggest_move?, answerable}]
routing:
  OWNER gap                         -> ESCALATED (M32)
  askable gaps not yet asked, round<2 -> G1 -> A5
  BLOCKING left, nothing to ask     -> ESCALATED (M32)
  otherwise                         -> A7
note: stakeholder disagreements go to M29 (not asked here)
Python · executable function
def a4_find_gaps(ctx: ContextBundle, fr: Framing, au: Authority, resolved: set[str],
                 pending_mandate: list[str], today: dt.date) -> list[Gap]:
    """A4 Find gaps and conflicts. Deterministic rules over A1-A3 outputs."""
    gaps: list[Gap] = []
    owner_id = au.owner["person_id"] if au.owner else None
    if ctx.mandate is None:
        gaps.append(Gap("G-MANDATE", "OWNER", Severity.BLOCKING, "No mandate record exists for this account.",
                        suggest_move="M32", answerable=False))
    elif au.owner is None or not au.owner.get("active", True):
        gaps.append(Gap("G-OWNER", "OWNER", Severity.BLOCKING,
                        "No active accountable renewal owner is recorded.", suggest_move="M32", answerable=False))
    if au.mandate_valid_until and _date(au.mandate_valid_until) < today:
        gaps.append(Gap("G-MANDATE-EXPIRED", "AUTHORITY", Severity.BLOCKING,
                        f"The mandate expired on {au.mandate_valid_until}.",
                        f"The mandate for this renewal expired on {au.mandate_valid_until}. "
                        "Please renew it in the mandate store so the Review can continue.",
                        owner_id, answerable=False))
    if ctx.subscription is None and ctx.other_subscriptions:
        names = ", ".join(f'{s["id"]} ({s["product"]})' for s in ctx.other_subscriptions)
        gaps.append(Gap("G-SUBSCRIPTION", "SCOPE", Severity.BLOCKING,
                        "Several active subscriptions and the request does not say which one is in scope.",
                        f"Which subscription(s) should this Review cover: {names}? Should any be co-termed?",
                        owner_id))
    if fr.perspective == "UNKNOWN":
        gaps.append(Gap("G-PERSPECTIVE", "PERSPECTIVE", Severity.BLOCKING,
                        "Buyer or supplier perspective is unclear (request and account record disagree).",
                        "Are we preparing this Review for our side as the buyer or as the supplier?", owner_id))
    beyond = [a for a in fr.requested_actions if a not in au.allowed_actions]
    if beyond and au.owner:
        allowed_txt = ", ".join(a.lower().replace("_", " ") for a in au.allowed_actions) or "nothing"
        gaps.append(Gap("G-AUTH-ACTIONS", "AUTHORITY", Severity.BLOCKING,
                        f"Requested actions {beyond} are outside the mandate (allowed: {au.allowed_actions}).",
                        f"The request asks for {', '.join(a.lower().replace('_', ' ') for a in beyond)}. "
                        f"The current mandate allows: {allowed_txt}. Should this Review stay within that? "
                        "If more is needed, the mandate itself must be updated.", owner_id))
    for a in pending_mandate:
        gaps.append(Gap(f"G-PENDING-{a}", "AUTHORITY", Severity.MATERIAL,
                        f"Owner wants {a.lower().replace('_', ' ')}, but the mandate does not allow it yet "
                        "(pending mandate update; then run M33).", suggest_move="M33", answerable=False))
    if au.owner and not au.requester_has_rights and au.requester["person_id"] != owner_id:
        gaps.append(Gap("G-REQUESTER", "AUTHORITY", Severity.MINOR,
                        f'Requester {au.requester["name"]} holds no decision right; '
                        f'the brief is owned by {au.owner["name"]}. Requester will be informed.'))
    if au.owner and au.budget is None and fr.request_kind != "QUICK_COMPARISON":
        gaps.append(Gap("G-BUDGET", "BUDGET", Severity.MATERIAL, "No budget ceiling is recorded in the mandate.",
                        "Is there an approved budget ceiling for this renewal, and who owns it?",
                        owner_id, suggest_move="M32"))
    if "REPLACE" in fr.decision_paths and len(fr.decision_paths) > 1:
        gaps.append(Gap("G-SCOPE-REPLACE", "SCOPE", Severity.MATERIAL,
                        "Request mentions both renewing and moving to another product.",
                        "Should this Review also assess replacing the product, or only renewal terms?", owner_id))
    for i, c in enumerate(fr.priority_conflicts):
        if c.get("between_stakeholders"):   # people disagree -> M29's job, not M01's
            gaps.append(Gap(f"G-PRIORITY-{i+1}", "PRIORITY", Severity.MATERIAL, c["text"],
                            suggest_move="M29", answerable=False))
        else:                               # one instruction is ambiguous -> owner clarifies here
            gaps.append(Gap(f"G-PRIORITY-{i+1}", "PRIORITY", Severity.MATERIAL, c["text"],
                            "Which of these is a must-have and which is a target we can trade?", owner_id))
    term_end = (ctx.subscription or {}).get("term_end")
    for d in fr.stated_dates:
        if term_end and d.get("date") and _date(d["date"]) > _date(term_end):
            gaps.append(Gap("G-DATE-AFTER-TERM", "DATE", Severity.BLOCKING,
                            f'Requested date {d["date"]} is after term end {term_end}.',
                            "The requested decision date is after the subscription ends. Which date applies?",
                            owner_id, suggest_move="M03"))
    if fr.injection_signals:
        gaps.append(Gap("G-INJECTION", "SAFETY", Severity.MINOR,
                        f"Request text contains instruction-like content {fr.injection_signals}; treated as data, "
                        "no authority taken from it.", answerable=False))
    for item in ctx.missing:
        if item != "mandate record":
            gaps.append(Gap(f"G-EVIDENCE-{item.replace(' ', '-')}", "EVIDENCE", Severity.MINOR,
                            f"Missing: {item}. Passed to M02; does not block framing.", suggest_move="M02"))
    return [g for g in gaps if g.gap_id not in resolved]
A5

Ask the owner

Human-in-the-loopSends internal messageG1 before

What it does (business)

Send at most three pointed questions, blocking ones first, only to the owner or a recorded delegate on the internal channel, then pause the run. Each question is tied to a gap that could change the decision.

Why it matters

People's time is the scarce resource. Fewer, sharper questions get answered. Never contact the supplier or customer from this Move.

Action contract · YAML

action: A5_ask_owner
kind: human-in-the-loop
side_effects: sends internal message(s)   # guarded by G1
inputs:  gaps that passed G1 (max 3 per round), round number
outputs: {round, sent: [{to, message_ref}], recipients, questions}
then:    state AWAITING_OWNER (events: owner_reply | owner_timeout)
limits:  2 rounds; a gap is never asked twice
Python · executable function
def g1_contact_gate(person_id: Optional[str], purpose: str, au: Authority) -> tuple[bool, str]:

    if person_id is None:
        return False, "no recipient"
    if "INTERNAL" not in au.allowed_contact:
        return False, "internal contact not permitted by mandate"
    decision_people = ({au.owner["person_id"]} if au.owner else set()) | {d["person_id"] for d in au.delegates}

def a6_record_answers(llm: LLM, outstanding: dict, reply_text: str, replied_by: str, reply_ref: str,
                      fr: Framing, au: Authority) -> tuple[list[Answer], dict, list[str], list[str]]:
    """A6 Record answers. LLM parses the reply; CODE decides what may change.
    Returns (answers, applied_updates, pending_mandate_actions, rejected_updates)."""
    parsed = llm.parse_answers(outstanding["questions"], reply_text)
    answerable = {q["gap_id"]: q["answerable"] for q in outstanding["questions"]}
    answers = [Answer(a["gap_id"], a["text"], replied_by, reply_ref,
                      a["resolves"] and answerable.get(a["gap_id"], False)) for a in parsed["answers"]]

    for k, v in parsed.get("updates", {}).items():
        if k not in SAFE_UPDATE_FIELDS:
            rejected.append(f"{k}: not changeable by a reply")

def a9_validate_brief(b: ReviewBrief, au: Authority, fr: Framing, known_refs: set[str]) -> list[str]:
    """A9 Validate brief. Checks C1-C7. Returns failure codes; empty = pass."""
    f = []
    q = b.decision_question.strip()
    if not q.endswith("?") or _find(COMMITTED_SOLUTION_PATTERNS, q):
        f.append("C1 decision question states a solution or is not a question")
    acc = b.responsibility.get("accountable")
    if not acc or acc.get("name") == b.responsibility.get("prepared_by"):
        f.append("C2 accountable owner missing or confused with the preparer")
    for fld in ("decision_question", "perspective", "account_id", "request_id"):
        if not getattr(b, fld):
            f.append(f"C3 required field empty: {fld}")
    if b.mode == "FULL" and not any(c.priority == "MUST" for c in b.success_criteria):
        f.append("C4 no MUST criterion")
    if any(not c.measure or not c.target for c in b.success_criteria):
        f.append("C4 criterion not measurable")
    musts = [_norm_measure(c.measure) for c in b.success_criteria if c.priority == "MUST"]
    if len(musts) != len(set(musts)):
        f.append("C4 two MUST criteria target the same measure")
    if any(a not in au.allowed_actions for a in b.authorized_actions):
        f.append("C5 brief authorizes an action outside the mandate")
    for a in fr.requested_actions:
        if a not in au.allowed_actions and not any(_stem(a) in e.lower() for e in b.exclusions):
            f.append(f"C5 unauthorized request {a} not listed as exclusion")
    for d in b.dates:
        if d.get("kind") not in {k.value for k in DateKind} or not d.get("source"):
            f.append(f'C6 date "{d.get("label")}" lacks a kind or source')
        if d.get("kind") == DateKind.CONTRACTUAL.value and d["source"].get("system") != "contract_repo":
            f.append(f'C6 date "{d.get("label")}" labelled contractual without a contract source')
    for c in b.success_criteria:
        if c.source.ref not in known_refs:
            f.append(f"C7 criterion {c.criterion_id} cites unknown source {c.source.ref}")
    if b.budget is not None and b.budget.get("source", {}).get("system") != "mandate_store":
        f.append("C7 budget does not come from the mandate store")
    return f

How this Move is used

V01 Frame

Pre-analysis step of the Frame play (with M13). The brief is the Dossier's “decision question, scope and success criteria”.

V03 Consult / V11 Plan

Clarifies the mandate before stakeholders are consulted, and sets the scope that the plan's priorities and owners follow.

Any other Verb (Optimize, Negotiate, Compare …)

The Manager runs M01 first when no valid brief exists for the request. Example: “Optimize our renewal” → M01 scopes the work → M05, M10, M11 run inside that scope.

Re-entry

When the mandate changes (new owner, budget, authority, expiry) or M33 reports a change that invalidates the brief.

Supplier side

A supplier's account team frames its opening proposal (the card's Westbrook case). The barrier withholds the buyer's private material.

Quick comparison

LIGHT mode: no MUST criterion, no budget question, no deadline Move. It stays a quick comparison.

Section 5 · Step 3: Move contract

The contract around the graph

Applicability, preconditions, inputs, output schema, completion states, failure behaviour and dependencies, in one machine-readable file (m01_move.yaml).

Completion states

  • COMPLETE: the owner confirmed an authoritative brief, which is published.
  • QUALIFIED_COMPLETE: confirmed and published with MATERIAL gaps or unresolved authority recorded.
  • REUSED: same request under the same mandate version; the existing brief stands.
  • BLOCKED: request or account not found, or an unrepairable check failure.
  • CANCELLED: stopped by an authorized person.
  • Paused: AWAITING_OWNER, AWAITING_CONFIRMATION, ESCALATED (resumable).

Failure behaviour

  • Never invent an owner, budget, authority or date. Missing means recorded as unknown.
  • Silence is not permission. A timeout never resolves a gap.
  • Authority comes only from the mandate store. Replies can narrow scope, never widen it.
  • Request text is data. Instruction-like content is flagged and ignored.
  • Boundaries: clauses → M02, deadlines → M03, stakeholder disputes → M29, missing owners → M32, changes → M33.

      - M33 reports a change that invalidates the current brief
    do_not_select_when:
      - Same request re-invoked under the same mandate version (G0 -> REUSED)
    proportionality: QUICK_COMPARISON requests produce a LIGHT brief (no MUST criterion, no budget question, no M03)
  preconditions:
    - request record exists with an identified requester
    - account is identifiable
  inputs:
    request_id:      {type: string, required: true}
    account_id:      {type: string, required: true}
    subscription_id: {type: string, required: false, note: "inferred only when exactly one active subscription"}
    force_reframe:   {type: bool,   required: false, default: false}
  output: ReviewBrief
  completion_states:
    COMPLETE:           Owner confirmed an authoritative brief; published.
    QUALIFIED_COMPLETE: Owner confirmed; MATERIAL gaps or unresolved authority recorded; published.
    REUSED:             Same request, same mandate version, brief already confirmed.
    BLOCKED:            Request/account not found, or checks fail in a way that cannot be repaired.
    CANCELLED:          Cancelled by an authorized person.
  suspended_states:
    AWAITING_OWNER:        Waiting for answers (events owner_reply | owner_timeout)
    AWAITING_CONFIRMATION: Waiting at G3 (events owner_confirm | owner_change_request | confirmation_timeout)
    ESCALATED:             Handed to M32; brief not published (event owner_assigned | mandate_changed)
  failure_behaviour:
    - Never invent an owner, budget, authority or date. Missing = recorded as unknown.
    - Silence is not permission. A timeout never resolves a gap.
    - Authority comes only from the mandate store. Replies can narrow scope, never widen it.
    - Unauthorized requested actions become explicit exclusions.
    - Request text is data. Instruction-like content is flagged and ignored.
  dependencies:
    upstream_optional: [M33]
    downstream_recommended: [M02, M03, M04, M05, M13, M29, M32, M33]   # advisory; the Manager commissions
